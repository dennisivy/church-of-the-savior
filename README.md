# Church of the Savior on Spilled Blood

Interactive exterior preview built with Three.js and Blender. Drag to rotate, scroll or pinch to zoom; choose Street view for a ground-level camera. Play resumes the automatic circuit.

Reference-informed work in progress, not a measured architectural survey. Exterior only.

## Asset attribution
See [Sources and credits](spilled-blood/credits.html) and the per-asset metadata under `assets/spilled-blood`. Artwork retains its individual attribution and license.

## Hosting
Static GitHub Pages site, published from the root of `main`. No build step. Three.js r170 and Draco decoders load from their configured CDNs.
